I’m the founder and lead engineer of [Hyperspace](https://hyperspace.zone), an open-source programmable VPN that issues standard WireGuard configurations and routes traffic through DoubleZero-backed ingress and egress gates.

Previously, I led integration engineering at Sensorium and worked on Web3 infrastructure partnerships.

## Featured open-source project

### [Hyperspace / 2z-wireguard-vpn](https://github.com/hyperspace-zone/2z-wireguard-vpn)

A production-oriented control plane for programmable multi-region WireGuard routing.

- TypeScript, Node.js and Fastify control plane
- Go gate agent managing WireGuard, routes and nftables
- PostgreSQL-backed desired-state reconciliation
- Automated multi-region deployment and gate management
- Latency, jitter and packet-loss benchmarking
- Prometheus, Grafana and Alertmanager observability
- Usage metering and programmable payment flows
- Public architecture documentation, tests and deployment runbooks
